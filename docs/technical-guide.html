Technical Guide

A deeper look at how the BL PCF Report workflow is built: the dual current/previous-period pipeline, colour mapping, every chart and map, and Word report and dashboard generation.

Download the full Technical Guide (PDF) v2.0

Version 2.0 rewrites the guide against the current spec.yaml. It corrects the dependency list (migrated to ecoscope-platform plus the Big Life, WWF-Virunga, STE, and MNC extension packages actually declared), the real chart/task names (several task names in the previous version matched nothing in spec.yaml), the previous-period mechanism (a flexible Custom/Preset/Calendar offset, not a simple integer), the Word report's fixed "Ecoscope" author field and overall_report.docx filename, and the dashboard, which wires up 24 widgets rather than an empty list. It also documents the unused gee_client connection field.
